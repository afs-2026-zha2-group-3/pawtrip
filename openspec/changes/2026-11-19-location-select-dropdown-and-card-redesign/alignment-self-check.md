## P3 决策与缺口

- **锚点清除入口**：设计只规定状态复位，未规定控件；P3 定为锚点 `Select` 的「不限景点」选项（值 `""`），不新增需求场景，由 E8 覆盖。
- **类型白名单实现位置**：`normalizeLocationType` 放入 `lib/location-summary.ts` 以支持单测，被 `validateSearch` 与页面共用。
- **E13 夹具不足**：单城市地点数均 < 20，真实分页不可达，采用 `page.route` 桩数据；桩结构必须与 `Page<LocationSummary>` 一致。
- **地图详情卡**：CI 无高德 JS Key，无法 E2E；由 U1 与 P4 走查覆盖，并在 `registry.md` 记「待本地带 Key 验证」。
- **景点页锚点控件**：Living Spec 保留条目但基线无控件；本次不新增不删除，DoV 已记录为残余项。
- **G1 已签署**：`g1-decision.md`（IO=kitty，SA=kitty，2026-11-19）；G2/G3 未签署，本文件不代签。
