# Spec Delta

## MODIFIED Requirements

### Requirement: 查询目的地的养犬政策

系统 SHALL 按行政区提供目的地养犬政策查询，返回政策条目、禁养犬种、可携带犬种、城市允许宠物类型、数据来源与更新时间。禁养犬种以可选犬种目录的犬种 id 关联保存；可携带犬种取自城市允许品种表，只从固定的可选犬种目录中选择。页面只展示禁养与可携带犬种的少量示例，MUST NOT 展示完整名单。政策内容为政府公开文件的人工摘录，仅收录已完成录入的城市。

#### Scenario: 查看已收录城市的政策
- **GIVEN** 目的地城市已收录养犬政策
- **WHEN** 用户查看该城市的政策
- **THEN** 系统展示该城市的政策条目，以及禁养犬种与可携带犬种的少量示例

#### Scenario: 展示犬种示例
- **GIVEN** 目的地城市已收录禁养犬种与可携带犬种
- **WHEN** 用户查看该城市的政策，无论当前品种是否命中禁养名单
- **THEN** 系统展示两类犬种的少量示例，并说明不是完整名单

#### Scenario: 可携带犬种未配置
- **GIVEN** 目的地城市已收录政策但后台尚未配置可携带犬种
- **WHEN** 用户查看该城市的政策
- **THEN** 系统展示"暂未收录可携带犬种"，MUST NOT 推断该城市允许携带

#### Scenario: 展示政策来源与时效
- **GIVEN** 用户查看已收录城市的政策
- **WHEN** 页面展示政策内容
- **THEN** 同时展示来源文件、更新月份和"以当地政府最新文件为准"的说明

#### Scenario: 返回城市允许宠物类型
- **GIVEN** 城市配置了允许宠物类型（如 `CAT,DOG`）
- **WHEN** 用户查询该城市的养犬政策
- **THEN** 响应同时返回 `allowedPetTypes`
- **AND** 未收录政策的城市也返回该字段，供匹配使用

### Requirement: 禁养犬种匹配与高亮提醒

系统 SHALL 使用统一政策匹配主体：存在激活行程且已绑定宠物时仅匹配该宠物，否则匹配当前用户全部宠物。犬只 SHALL 按其犬种 id 同时与目的地城市的禁养犬种关联和可携带犬种关联比较，并以宠物名 tag 展示结论。命中禁养关联时 SHALL 给出高亮提醒并说明可能后果；未命中禁养但在可携带关联中时 SHALL 明确告知未命中禁养名单。宠物为猫时，系统 SHALL 按城市允许宠物类型判定：允许猫 SHALL 展示友好，页面以现有「未命中禁养名单」文案与宠物名 tag 呈现即可，不要求额外解释禁养犬种名单是否适用；不允许猫 SHALL 展示不友好，MUST NOT 显示无法判定。犬只没有可用犬种信息、品种 id 不在可选犬种目录，或品种既不在禁养关联也不在可携带关联时，系统 MUST NOT 给出命中或未命中的结论，仅展示通用政策。

#### Scenario: 品种命中禁养名单
- **GIVEN** 匹配主体的宠物档案包含犬种，且该犬种 id 与目的地城市的禁养犬种关联一致
- **WHEN** 用户查看该城市的政策
- **THEN** 系统显示该宠物的禁养 tag 和高亮提醒，指出命中的宠物与品种，并说明该城市政策不支持携带该宠物旅行

#### Scenario: 品种未命中禁养名单
- **GIVEN** 匹配主体的宠物档案包含犬种，且该犬种 id 在目的地城市的可携带犬种关联中、不在禁养关联中
- **WHEN** 用户查看该城市的政策
- **THEN** 系统明确提示该宠物未命中禁养名单，并说明仍需遵守其他规定

#### Scenario: 品种既不在禁养也不在可携带名单
- **GIVEN** 匹配主体的犬只档案包含犬种，但该犬种 id 既不在禁养关联也不在可携带关联中
- **WHEN** 用户查看该城市的政策
- **THEN** 该宠物 tag 显示无法判定，系统不做禁养判定并说明暂时无法判断

#### Scenario: 猫按城市允许类型显示友好
- **GIVEN** 匹配主体包含一只猫，且城市允许宠物类型包含猫
- **WHEN** 用户查看该城市的政策
- **THEN** 该宠物 tag 显示友好
- **AND** 页面以现有「未命中禁养名单」文案呈现，不要求额外解释禁养犬种名单是否适用

#### Scenario: 城市不允许携带猫
- **GIVEN** 匹配主体包含一只猫，且城市允许宠物类型不包含猫或为 null
- **WHEN** 用户查看该城市的政策
- **THEN** 该宠物 tag 显示不友好
- **AND** 原因说明该城市不允许携带猫

#### Scenario: 没有宠物档案
- **GIVEN** 用户没有添加宠物
- **WHEN** 用户查看该城市的政策
- **THEN** 系统不做禁养判定，并提示先完善宠物档案

#### Scenario: 宠物没有犬种信息
- **GIVEN** 匹配主体的犬只档案没有犬种信息（猫不适用本条，按允许类型判定）
- **WHEN** 用户查看该城市的政策
- **THEN** 该宠物 tag 显示无法判定，系统不做禁养判定

#### Scenario: 品种不在可选犬种目录
- **GIVEN** 查询使用的犬种 id 不在可选犬种目录中
- **WHEN** 系统执行禁养匹配
- **THEN** 系统不做禁养判定，并说明暂时无法判断

#### Scenario: 禁养犬种关联为空
- **GIVEN** 目的地城市已收录政策但未配置禁养犬种关联
- **WHEN** 用户查看该城市的政策
- **THEN** 系统不得给出禁养命中结论；品种在可携带关联中时按未命中处理，否则不判定

#### Scenario: 存在激活行程时只判定激活宠物
- **GIVEN** 用户存在激活行程且已绑定一只宠物，同时还有其他宠物
- **WHEN** 用户查看该城市的政策
- **THEN** 系统只展示该激活宠物的匹配结论
- **AND** 不为其他宠物给出结论
