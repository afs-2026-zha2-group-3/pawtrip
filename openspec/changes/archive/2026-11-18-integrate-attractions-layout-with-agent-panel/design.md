## Context

`apps/web` 的地点在页 `/attractions` 当前在 `xl`（≥1280px）使用四栏网格：`220px` 行程面板、地点卡片列表、地图列与最右 `260–340px` 的灰色 AI 占位（`data-testid="ai-chatbox-slot"`）。卡片列表固定每行 2 张（`sm:grid-cols-2`）。Agent 面板是挂在 `_authenticated` 全局布局上的 shadcn Sheet：`fixed`、右侧 400px、`right-4`、`inset-y-4`，开合状态存于 `agentStore.open`，页面可通过 `useAgentOpen()` 订阅；面板与地点页之间没有任何布局联动。

结果是：面板收起时右侧灰色占位形成无意义空白；面板展开时又悬浮覆盖地图。验收目标为桌面 1920×1080，约束是**不改变面板自身的悬浮形态**，只让地点页让位。

## Goals / Non-Goals

**Goals:**

- 视口 ≥1536px（`2xl`，覆盖 1920×1080）时，地点页按面板开合切换布局：收起为三栏、卡片三列、地图贴右；展开为卡片两列、右侧约 376px 透明留白承载悬浮面板。
- 删除灰色 AI 占位；地图列宽变化后仍正确渲染。
- 面板组件、开合状态来源与交互方式保持不变。
- 以 1920×1080 为验收视口补充 E2E；1280 视口行为不回退。

**Non-Goals:**

- 不把 Agent 面板改为停靠式/嵌入式，不调整其 400px 宽度、位置、z-index 或小屏全屏行为。
- 不改动其他页面的面板覆盖行为。
- 不引入面板开合状态的持久化；刷新后仍为收起。
- 不为 `1536px` 以下视口设计三列卡片或留白。
- 不改后端、地点查询、地图点位与筛选逻辑。

## Decisions

### 以 `2xl`（≥1536px）作为自适应断点

1920×1080 下内容区宽 1840px（`lg:px-10` 左右各 40px），足以同时容纳三列卡片或“两列卡片 + 376px 留白”。1280px 下若强行三列，卡片约 160px；若再为面板预留留白，地图只剩约 240px，均不属于本次目标。因此：

- `<2xl`：保持既有 `lg` 三栏网格与 `sm:grid-cols-2`，面板展开时仍悬浮覆盖内容。
- `≥2xl`：启用自适应布局。

不采用 `xl` 断点，避免在 1280–1535 引入可用性下降；也不引入自定义 1920 断点，`2xl` 已覆盖验收视口且是现有 Tailwind 断点。

### 页面订阅 `useAgentOpen()`，不新增状态

布局直接由 `agentStore.open` 派生，`AgentPanel` 仍由同一 store 控制，无需新增 context、prop 透传或 CSS 变量广播。页面在 SSR 阶段返回 `null`，客户端首帧读取内存状态（默认 `false`），不存在水合不一致。不采用 `:has()` 或监测面板 DOM：状态源头是 store，直接订阅最稳定。

### 两种 `2xl` 网格模板与卡片列数

保持 `lg` 网格作为基础，仅在 `2xl` 覆盖：

```
收起：2xl:grid-cols-[220px_minmax(0,1fr)_minmax(320px,0.8fr)]
展开：2xl:grid-cols-[220px_minmax(0,1fr)_minmax(240px,0.85fr)_minmax(0,376px)]
```

1920×1080 下的测算（内容 1840px，网格间距 16px，卡片间距 24px）：

| 状态 | 行程 | 列表 | 地图 | 留白 | 卡片宽度 |
|------|------|------|------|------|----------|
| 收起 | 220 | 882 | 706 | — | 约 278px（3 列） |
| 展开 | 220 | 646 | 550 | 376 | 约 311px（2 列） |

- 展开时地图右缘 = 内容右缘（1880）− 留白 376 − 网格间距 16 = 1488；面板左缘 = 1920 − 16 − 400 = 1504，留 16px 间距，地图不被遮挡。
- 空轨宽度 376px = 面板宽度 400px + 面板右侧偏移 16px − 页面右内边距 40px；再靠网格间距 16px 与地图分隔。该数值与 Agent 面板样式耦合，实施时在两处加注释互相指向；面板宽度若变更必须同步此值。
- 卡片网格：`agentOpen ? "sm:grid-cols-2" : "sm:grid-cols-2 2xl:grid-cols-3"`。两份模板都写成静态 class 字符串，保证 Tailwind 扫描；不拼接动态类名。
- 不采用 `margin-right`/`padding-right` 整体压缩方案：网格末列可以明确承载留白，且与列表/地图的列定位一致，避免 `main` 内边距与位置计算耦合。
- 不为布局切换加动画：3 轨↔4 轨无法平滑插值，且会连续触发地图 resize；保持即时切换。

### 删除 AI 占位并让地图贴右

删除 `ai-chatbox-slot` 元素及其样式。收起态下地图是最后一列，`grid` 列宽自然延伸到内容右缘；无需额外 `justify` 或尾部 spacer。地点列表仍是可纵向滚动的中间列，筛选、分页与详情弹窗逻辑不变。

### 地图监听容器尺寸并调用 `resize()`

高德 JS API 2.0 的 `Map` 在容器尺寸变化后需要显式 `resize()`，否则瓦片、视野与信息窗位置会按旧尺寸绘制。当前 `LocationMap` 未监听容器尺寸，`AMapMap` 类型也未声明 `resize()`。

- 在 `lib/amap/loader.ts` 的 `AMapMap` 接口补充 `resize(): void`。
- 在 `LocationMap` 中当 `status === "ready"` 时为容器注册 `ResizeObserver`，尺寸变化时调用 `map.resize()`；清理时断开 observer。使用 observer 而非仅在 `agentOpen` 变化时触发，可同时覆盖窗口缩放与浏览器缩放。
- 回调内只调用 `resize()`，不触发 `setFitView`，避免用户已手动缩放/平移的视野被重置。
- E2E 未配置高德 Key，走 `location-map-placeholder`，因此布局断言不依赖地图 SDK；`resize()` 行为由组件层面保证，若需自动化验证可在组件测试中 mock `AMapMap`。

### E2E 的视口与断言

- 新增一组 `test.describe` 或 `test.use({ viewport: { width: 1920, height: 1080 } })` 的用例；默认 1280×720 的既有用例不改。
- 收起态：取前 3 张 `[data-slot="card"]` 的 bounding box，断言第 3 张与第 1 张同行（`y` 接近）且 `x` 大于第 1 张 `x + width`；断言 `ai-chatbox-slot` 不存在；断言地图占位右缘与页面内容右缘误差 ≤ 1px（可用 `main` 的 bounding box 计算内容右缘）。
- 展开态：通过 `agent-fab` 展开面板；断言第 3 张卡片进入下一行、地图占位右缘 ≤ 面板左缘（`agent-panel` bounding box）。
- 窄屏回归：在现有 1280 用例中补一条断言，展开面板后卡片仍为两列且不存在 376px 留白轨（可通过第三张卡片仍在第二行判断）。
- 移除原 “four-column attractions layout reserves the AI chatbox slot” 用例。

## Risks / Trade-offs

- **留白宽度与面板宽度硬编码耦合** → 376px 与 `agent-panel.tsx` 的 `w-[400px]`、`right-4` 强相关；在两侧加互相引用的注释，变更面板宽度时同步修改，并靠 1920 视口 E2E 兜底。
- **固定像素网格在 1536–1919 之间偏紧** → 展开态列表约 430px、地图约 366px，仍可用；收起态三列卡片约 210–260px。若后续需要更平滑，可改为 CSS 变量或容器查询，本期不做。
- **地图 `resize()` 不存在或版本差异** → 高德 2.0 提供该方法；类型接口补充后由运行期兜底（调用前判空）。E2E 不加载 SDK，真实地图需人工在 1920 视口确认一次。
- **布局即时切换引发布局抖动** → 无动画，面板开关本身是用户主动操作；若抖动明显再考虑 `transition` 或 view transition，本期不做。
- **卡片三列时按钮换行** → 1920 下卡片约 276px，与当前两列 284px 接近，按钮与标签的换行行为无明显变化；在 1920 E2E 与人工验收中确认。
- **`TripPanel` 在窄屏会覆盖卡片** → 既有限制，不在本次范围内；E2E 仍沿用 `hideTripPanel` 辅助函数。

## Migration Plan

无数据库或 API 迁移。上线后地点页在 `2xl` 下即时生效；回滚只需恢复原网格类名与占位元素。无持久化状态需要清理。
