## MODIFIED Requirements

### Requirement: 地点浏览与 Agent 面板的自适应布局

地点浏览页 SHALL 在视口宽度 ≥1024px 时采用固定三栏布局：行程面板、地点列表与地图三栏 MUST 占满内容区可用高度，地图列 MUST 固定且 MUST NOT 随地点列表滚动；仅地点列表与行程面板内容 SHALL 在各自列内纵向滚动，页面 MUST NOT 产生文档级滚动。布局 MUST NOT 依赖基于顶部导航高度的视口减法（如 `100svh - 80px`）。视口宽度 <1024px 时，三栏 SHALL 按内容区整体滚动堆叠展示。地点浏览页 SHALL 在视口宽度 ≥1536px 时根据全局 Agent 面板的开合状态调整桌面布局，且 MUST NOT 改变 Agent 面板的悬浮形态（固定右侧 400px Sheet）。面板收起时，主内容 MUST 为“行程面板 / 地点列表 / 地图”三栏，地点卡片列表 SHALL 每行 3 张，地图 MUST 占据剩余宽度且右缘与页面内容右缘对齐，页面 MUST NOT 保留 AI 占位区域或右侧空白。面板展开时，地点卡片列表 MUST 保持每行 2 张，页面 SHALL 在内容右侧保留不小于 360px 的透明留白承载面板，地图 SHALL 相应收窄且其可见区域 MUST NOT 被面板覆盖。视口宽度 <1536px 时，页面 MUST 保持既有两列卡片布局，不要求为面板让位。布局 MUST 实时响应面板开合，状态仅来自内存。

#### Scenario: 面板收起时三栏三列且无右侧空白

- **GIVEN** 视口为 1920×1080 且存在激活行程
- **WHEN** 用户打开地点浏览页且 Agent 面板处于收起状态
- **THEN** 主内容显示行程面板、地点列表与地图三栏
- **AND** 地点卡片每行显示 3 张
- **AND** 地图右缘与页面内容右缘对齐
- **AND** 页面不存在 AI 占位区域或额外右侧空白

#### Scenario: 面板展开时列表两列并为面板让位

- **GIVEN** 视口为 1920×1080 且存在激活行程
- **WHEN** 用户展开 Agent 面板
- **THEN** 地点卡片保持每行 2 张
- **AND** 页面右侧保留不小于 360px 的透明留白
- **AND** 地图收窄且地图右缘位于面板左缘左侧，不被面板覆盖

#### Scenario: 开合实时切换布局

- **GIVEN** 用户位于地点浏览页
- **WHEN** 用户通过右下角入口展开或收起 Agent 面板
- **THEN** 地点浏览页在收起态与展开态布局之间实时切换
- **AND** 不刷新页面、不丢失当前筛选、分页与搜索条件

#### Scenario: 窄于断点时保持现状

- **GIVEN** 视口宽度小于 1536px 且存在激活行程
- **WHEN** 用户打开地点浏览页并展开 Agent 面板
- **THEN** 地点卡片保持每行 2 张
- **AND** 页面不为面板预留右侧留白
- **AND** 面板以既有悬浮方式显示

#### Scenario: 地图在列宽变化后保持正确显示

- **GIVEN** 地点页地图已加载
- **WHEN** Agent 面板开合导致地图列宽度变化
- **THEN** 地图内容按新宽度重新适配
- **AND** 瓦片不出现空白或被裁切

#### Scenario: 桌面端三栏定高且仅局部滚动

- **GIVEN** 视口为 1920×1080 且存在激活行程与足够多的地点
- **WHEN** 用户滚动地点列表
- **THEN** 地点列表列内部 `scrollTop` 增大
- **AND** 地图列的包围盒位置与尺寸保持不变
- **AND** `window.scrollY` 保持为 0

#### Scenario: 行程面板内容独立滚动

- **GIVEN** 桌面端地点浏览页的行程面板内容超过其列高
- **WHEN** 用户滚动行程面板列表
- **THEN** 行程面板列表内部滚动
- **AND** 地点列表与地图列的包围盒位置保持不变
- **AND** 行程面板页脚保持可见

#### Scenario: 窄视口保持整体滚动

- **GIVEN** 视口宽度小于 1024px 且存在激活行程
- **WHEN** 用户滚动地点浏览页
- **THEN** 行程面板、地点列表与地图按内容区整体滚动
- **AND** 不出现列级独立滚动容器
