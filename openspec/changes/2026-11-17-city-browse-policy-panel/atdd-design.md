# ATDD Design

变更：`2026-11-17-city-browse-policy-panel`

性质：本记录为 P3 计划工件；实际落盘晚于实现，属于回溯记录，只用于对齐 Scenario 与最终 E2E，不作为 TDD 证据。

## ATDD layers in scope

### API 层

不新增或修改后端接口。侧栏复用既有 `GET /api/cities/{adcode}/pet-policy`；候选接口的 `policyCovered`/`bannedBreeds` 保持占位。数据层只保留一条 V26 迁移写入 8 个首页城市的公开政策摘录与上饶 8 条禁养映射，不含演示数据。

### Unit 层

分页与侧栏状态内联在 `cities.tsx`，未新增单测。匹配与查询复用既有 `matchCityPolicy`、`cityPetPolicyQueryOptions`，其口径由既有政策单测覆盖。本变更以 E2E 与类型检查作为主要证据。

### E2E 层

`e2e/destination-selection.spec.ts` 使用真实后端与全新临时数据库；`e2e/trip-helpers.ts` 新增 `searchCity`，`openTripDialog` 在定位卡片前自动搜索，避免分页导致目标城市不在第一页。

## What is written before production code

本记录为回溯对齐，不是 TDD 证据。按正常顺序应先写：

1. E16 分页、禁用态、多页关键词重置与计数不变；E1 单页 9 张。
2. E8/E15/E18/E20 卡片无链接、点击与键盘开侧栏、必填字段、关闭与几何。
3. E17 第一页公开数据、来源、三沙未收录；E19 上饶部分名单与 8 条映射。
4. E21 侧栏友好/不友好三态结论。
5. `city-pet-policy.spec.ts` 侧栏到完整政策页。
6. 适配分页的既有用例与 `trip-helpers.ts`。

## Non-goals

- 不新增服务端分页接口或缓存键。
- 不验证真实政府网站的可访问性；可核验性限定为来源标题与说明可读、人工抽样，政策表无 `source_url`。
- 不做像素级截图比对；E20 只断言宽度、左右位置与堆叠关系。
- 不为侧栏复制一套匹配单测；复用既有判定函数。
